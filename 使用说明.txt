结构工程师知识库 · 使用说明
================================

一、怎么打开使用
  1. 先解压整个压缩包到任意目录（保持文件夹结构完整）
  2. 双击打开「index.html」即可使用，无需安装任何软件、无需联网（B站/图库链接除外）
  3. 或直接用线上链接打开（推荐，永远是最新版）

二、这个知识库有什么（六大模块）
  【📚 知识库】166 条知识点，12 大领域
      - 材料应用、成型与加工、模具与DFM、结构设计、工程制图与公差、表面处理、
        光学设计、散热设计、安规认证、测试验证、包装与物流、成本与量产
      - 每条含：核心要点、应用场景、关键经验数值速记、深度解析（5 节）、
        关联知识点跳转、示意图（可点击放大）、视频解说（B站/YouTube 直达）

  【📊 速查手册】11 张表、164 行数据
      - 常用塑料特性对比 / 注塑结构设计速查 / 公差与配合速查 / 螺丝与紧固速查
      - 金属材料与钣金速查 / 钣金与机加工速查 / 表面处理对比 / 安规与防护等级速查
      - 光学参数速查 / 包装与运输速查 / 成本与量产速查
      - 顶部搜索框可在当前表格内即时筛选

  【✅ 检查清单】5 份、共 114 项
      - 开模前结构评审（31 项）/ DFM 检讨清单（23 项）/ 安规自检清单（22 项）
      - 试产与量产准备（20 项）/ 包装与运输评审（18 项）
      - 逐项勾选，进度自动保存在本机浏览器；可一键打印成纸质清单

  【🧩 整机案例】3 款塑料灯具完整拆解
      - 硅胶拍拍小夜灯 / 桌面 RGB 氛围灯 / 便携补光灯
      - 每款含：结构构成与选材表、关键设计参数、开发流程与工艺路线、
        常见问题与对策、成本构成估算

  【📖 术语词典】139 个中英术语
      - 覆盖材料、成型模具、结构装配、制图公差、光学、热与安规、测试质量、项目量产
      - 可按分类筛选或直接搜索

  【🗺️ 学习路径】新人 30 天上手计划
      - 按 4 周拆到天：每天读哪几条、做什么练习、产出什么成果
      - 每天的知识点标签可直接点击打开详情

三、常用操作
  - 顶部六个模块按钮自由切换；按 Esc 可快速回到知识库
  - 首页 = 领域总览：点领域卡片 → 看「需要掌握的能力」清单 + 知识点明细
  - 全局搜索框：输入关键词，实时过滤（名称/要点/场景）
  - 「只看核心必会」：一键筛出核心重点，建议按顺序学
  - 点表格任意一行：右侧滑出详情面板（要点 / 应用 / 经验数值 / 深度解析 / 关联 / 视频 / 图）
  - 学习进度：点行内状态标签（待学习 → 学习中 → 已掌握）循环切换

四、常见问题
  - 打开后图片不显示：请确认 index.html 与 images 文件夹在同一目录且未改名
  - 学习进度与清单勾选存在浏览器本地，换电脑/清缓存会清空，属正常现象
  - 强烈建议使用 Chrome / Edge 浏览器打开（360、IE 等旧内核可能显示异常）

  需要增删知识点或配图，找作者更新后重新发布即可。
