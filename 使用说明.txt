结构工程师知识库 · 使用说明
================================

一、怎么打开使用
  1. 直接打开线上链接即可（推荐，永远是最新版）
  2. 或解压整个包到任意目录（保持文件夹结构完整），双击「index.html」
     无需安装任何软件、无需联网（B站/图库链接除外）
  3. 建议用 Chrome / Edge 打开（360、IE 等旧内核可能显示异常）

二、这个知识库有什么（十一大模块）
  ── 学习线（按「学→查→练→考」闭环设计）──

  【📚 知识库】166 条知识点，12 大领域
      材料应用、成型与加工、模具与DFM、结构设计、工程制图与公差、表面处理、
      光学设计、散热设计、安规认证、测试验证、包装与物流、成本与量产
      每条包含 8 个部分，图文并茂：
        核心要点 / 应用场景 / 关键经验数值速记 / 深度解析（5 节）/
        动手练习（含验收点）/ 关联知识点（可点击跳转）/
        视频解说 / 主图 + 参考图集（每条约 3 张实景参考图，可点击放大）

  【🧭 学习地图】12 个领域的学习顺序
      每个领域按「先学什么→后学什么」分成 4-6 层，
      每一层说明为什么这样排，每条知识点写明「学它的意义」。
      按层往下走不会走弯路，点任意知识点直接打开详情。

三、常用操作
  - 顶部两行模块按钮自由切换：上行是「学习」，下行是「参考」
  - 【首页双面板】
      · 内容总览：14 个数字，点任意数字直接进入对应模块
      · 我的学习进度：知识掌握率 / 自测正确率 / 清单完成度 + 12 个领域掌握率，
        底部给出「下一步建议」（按你的实际进度自动推荐下一步该做什么）
  - 【全站搜索】顶部搜索框一次搜遍全站：
      知识点、术语词典、标准清单、缺陷排查、面试题库、速查手册、自测题库、整机案例，
      结果按模块分组显示；点分组标题可进入该模块查看全部命中
  - 【详情面板】
      · 上一条 / 下一条：连续学习不用关掉再点，直接翻页
      · 区块跳转条：📌要点 / 💡应用 / 🔢数值 / 📖深度 / 🔗关联 / ✍️练习 / 🎬视频 / 📷图集，一点直达
      · 按 Esc 关闭面板
  - 【实战宝典】顶部搜索框可在当前分类内筛选（72 项标准也能搜）
  - 【参考图库】可按 12 个领域筛选、按图注搜索；点图片放大、点标题跳知识点；
      首屏 60 张，点「加载更多」继续
  - 【点缩略图】列表里的小方图点一下直接放大看大图（不会打开详情）；
      点行的其他位置才打开详情面板
  - 列表「示意图」列出现绿色「＋3」角标，表示该条另有 3 张参考图
  - 学习进度：点行内状态标签（待学习 → 学习中 → 已掌握）循环切换
  - 右下角「↑」按钮：长页面一键回到顶部

四、常见问题
  - 打开后图片不显示：请确认 index.html 与 images 文件夹在同一目录且未改名
  - 学习进度、清单勾选、答题记录都存在浏览器本地，换电脑/清缓存会清空，属正常现象
  - 计算器结果是工程估算值，用于方案阶段快速判断，正式设计需按实际数据核算
  - 参考图为公开网络资料，仅作学习参考，版权归原作者；图注下方标注了来源域名
  - 建议用 Chrome / Edge / Safari 等新版浏览器打开

六、后续更新
  内容与页面分离：改数据只需动对应的 .js 文件，页面会自动呈现。
  新增配图时记得同时生成缩略图（images/thumb/ 与 images/ref/thumb/），
  否则列表与图库会回退到加载原图，速度会明显变慢。
  需要增删知识点或配图，找作者更新后重新发布即可。
